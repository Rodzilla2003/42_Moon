# Проверка лунного сценария

Численные расчёты выполнены настоящей программой `42sh_moon`, собранной из приложенных исходников на macOS `arm64`. Qt проверен с `Qt 5.15.19` и платформой `offscreen`.

- `capture`: импульс включён; `6,201` витка, высота `298,464–301,799 км`, удельная энергия отрицательна, эксцентриситет меньше `0,001`.
- `no_capture`: те же начальные условия без импульса; к `440000 с` аппарат удалился от Луны примерно на `52866,6 км` над поверхностью, энергия положительна.
- `step_2_5`: внутренний шаг уменьшен с `5` до `2,5 с`; сравнение в общие моменты времени после импульса даёт расхождение положения до `6,48 м`.
- Все записанные значения конечны, время не убывает, пересечений поверхностей Земли и Луны не обнаружено. Повтор времени в момент импульса обозначает два разных состояния скорости при одном положении.
- Повторный подбор начальной скорости через `shoot_launch.py` сошёлся.
- Qt собран, расчёт выполнен полностью, графики просмотрены. Снимок окна — `results/qt_window.png`.
- Вариант Qt с 3D собран на macOS. Интерактивная сцена 3D и Windows MinGW не запускались.
- Конфигурация `.pro` разобрана штатным `qmake` на macOS. Попытка проверки Windows-компиляции на этом компьютере остановилась на отсутствии MinGW; успешная Windows-сборка не заявляется.
- У исходного DOCX сохранена отдельная копия. Первые пять страниц дополненного отчёта совпадают с оригиналом при сравнении отрисованных страниц по пикселям. Новые страницы проверены визуально.

Воспроизведение численных проверок: `python lab/verify_mission.py --binary <путь-к-программе>`. Для запуска нужны рабочий каталог `42`, исходные ресурсы `Model` и `World`; проверки сами создают отдельные временные сценарии.

Начало расчёта — состояние после идеального импульса ухода с околоземной орбиты. Солнечная гравитация, J2, расход топлива и конечная длительность тяги не учитываются. Вывод о связанности относится к рассчитанным `14,2 часа` после импульса.
